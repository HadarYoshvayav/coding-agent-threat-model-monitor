# Coding Agent Threat Model & Monitor

An independent project exploring security risks in coding agents, with a focus on insider-style threats, attack paths, and practical detection.

## Goals

- Map potential attack paths involving coding agents.
- Build a structured library of failure modes.
- Explore how suspicious agent behavior can be detected from event logs.
- Evaluate detection logic against malicious and benign scenarios.

## Scope

The project starts with synthetic event data and simple detection rules. It does not attempt to prove that an agent is misaligned or that a security incident has occurred.
